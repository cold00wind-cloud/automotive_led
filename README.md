# Automotive_led

Навчальний embedded-проєкт на **ESP32-S3** (Arduino framework, PlatformIO): керування двома світлодіодами за допомогою двох кнопок і фоторезистора (LDR). Логіка організована як простий скінченний автомат із трьох режимів; увесь код неблокуючий (на `millis()`, без `delay()`).

## Апаратна частина

| Компонент            | Пін (GPIO) | Примітка                                         |
|----------------------|:----------:|--------------------------------------------------|
| Фоторезистор (LDR)   | 2          | Аналоговий вхід (ADC)                            |
| Білий світлодіод     | 17         | `LED_W`                                          |
| Жовтий світлодіод    | 16         | `LED_Y`                                          |
| Кнопка «BLINK»       | 21         | `BTN_BLINK`                                      |
| Кнопка «CRASHED»     | 20         | `BTN_CRASHE`                                     |

- Кнопки налаштовані як `INPUT_PULLDOWN`: у спокої читається `LOW`, натискання = `HIGH`, тож другий контакт кнопки підключається до **3V3**.
- Світлодіоди підключаються через струмообмежувальні резистори.
- LDR вмикається в дільник напруги, середня точка — на GPIO 2.

Плата: `esp32-s3-devkitc-1`.

## Режими роботи

| Режим     | Поведінка                                                              |
|-----------|------------------------------------------------------------------------|
| `NORMAL`  | Білий LED світиться, коли темно (за показаннями LDR); жовтий вимкнений    |
| `BLINK`   | Жовтий LED блимає з періодом 700 мс                                    |
| `CRASHED` | Аварійний режим: жовтий блимає 200 мс, білий — 300 мс                  |

Переходи між режимами:

```
          BLINK
NORMAL ◄──────────► BLINK
   │                  │
   │ CRASHED          │ CRASHED
   ▼                  ▼
      CRASHED ── CRASHED ──► NORMAL
```

- Кнопка «BLINK»: `NORMAL` ↔ `BLINK`.
- Кнопка «CRASHED»: з `NORMAL` або `BLINK` → `CRASHED`; повторне натискання → `NORMAL`.
- У `CRASHED` кнопка «BLINK» ігнорується.
- При кожній зміні режиму обидва світлодіоди спершу гасяться.

## Модулі

- **`Button`** — опитування кнопки з програмним дебаунсом (100 мс). `wasPressed()` повертає `true` один раз на натискання й скидає прапорець.
- **`Led`** — `set(bool)`, `isOn()` та неблокуюче `blink(periodMs)`.
- **`Ldr`** — читає АЦП кожні 10 мс, згладжує значення й визначає темряву з **гістерезисом**, щоб LED не «дрижав» на межі порогів.
- **`MovingAverage`** — ковзне середнє по `N = 32` останніх вимірах.

### Параметри (`include/config.h`)

| Константа            | Значення | Опис                                              |
|----------------------|:--------:|---------------------------------------------------|
| `LDR_THRESHOLD_ON`   | 1000     | Нижній поріг: значення нижче → «темно»            |
| `LDR_THRESHOLD_OFF`  | 1100     | Верхній поріг: значення вище → «світло»           |
| `ADC_PERIOD`         | 10 мс    | Період опитування АЦП                             |
| `DEBOUNCE_MC`        | 100 мс   | Час дебаунсу кнопок                               |
| `N`                  | 32       | Розмір вікна ковзного середнього                  |

Між порогами 1000 і 1100 стан зберігається попереднім. Пороги залежать від схеми дільника та освітлення — за потреби підлаштуйте їх під своє залізо.
